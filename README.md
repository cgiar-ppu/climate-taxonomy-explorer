# Climate Taxonomy v5 Explorer

An interactive, read-only explorer for the CGIAR Climate Adaptation and Mitigation Taxonomy v5.0.0-draft — a static single-page app (no backend) published with GitHub Pages at https://cgiar-ppu.github.io/climate-taxonomy-explorer/. Every push to `main` runs `npm ci && npm run build` on Node 20 and deploys `dist/` through the `pages.yml` workflow on GitHub-hosted runners.
